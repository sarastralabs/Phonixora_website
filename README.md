# Phonixora - Sustainable Packaging Solutions

A modern, eco-friendly website built with Next.js showcasing biodegradable packaging solutions.

## Features

- 🎨 Beautiful design inspired by nature
- 🌱 Eco-friendly branding with green color palette
- 📱 Fully responsive layout
- ⚡ Built with Next.js 14 and TypeScript
- 🎭 Smooth animations and transitions
- 📧 Contact form for inquiries
- 🖼️ Modern gallery section for office and plant images

## Sections

- **Home**: Hero section with animated visuals
- **About Us**: Company mission and key benefits
- **Products**: Showcase of eco-friendly packaging solutions
- **Gallery**: Office and manufacturing plant images
- **Contact**: Get in touch form with company information
- **Footer**: Links and certifications

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Adding Images

### Hero Section Image
Place your agriculture-related image at:
- `public/images/hero-agriculture.jpg`
- Recommended: High-quality image showing sustainable farming, biodegradable packaging in agricultural setting, or eco-friendly crops
- Resolution: 1200x1400px or higher
- Format: JPG or PNG

### Gallery Images

Place your images in the `public/images/` folder with these names:

### Office Images:
- `office-1.jpg` - Main office/workspace (featured large image)
- `office-2.jpg` - Team collaboration area
- `office-3.jpg` - Research & Development center

### Plant/Manufacturing Images:
- `plant-1.jpg` - Manufacturing facility
- `plant-2.jpg` - Quality control/testing lab
- `plant-3.jpg` - Raw materials/storage area

**Recommended image specifications:**
- Format: JPG or PNG
- Resolution: 1920x1080px or higher
- Aspect ratio: 16:9 or 4:3
- File size: Under 500KB (optimized for web)

The gallery uses a modern masonry-style grid layout that automatically adapts to different screen sizes.
